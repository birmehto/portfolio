# Bir Mehto | Mobile Engineer Portfolio

A premium portfolio built with Next.js, featuring a modern "Midnight" theme, glassmorphism, and smooth animations.

## 🚀 Features

- **Modern UI**: Midnight dark theme with vibrant accents.
- **Glassmorphism**: Sleek, frosted-glass components.
- **Bento Skills**: Organized, interactive skills grid.
- **Dynamic Projects**: Showcase of mobile applications and packages.
- **Responsive**: Fully optimized for mobile, tablet, and desktop.
- **Performance**: Built with Next.js 15+ for speed and SEO.

## 🛠️ Tech Stack

- **Framework**: Next.js 15
- **Styling**: Vanilla CSS (Modules)
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Theme**: Next-Themes

## 📦 Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
